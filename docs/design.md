# Design System

## Theme & Vibe
*   **Style:** Corporate, Data-Dense, High-Trust.
*   **Vibe:** A modern SaaS product built for the government. Clean, no flashy animations, prioritized readability.

## Color Palette
*   **Primary (Brand):** `Navy Blue` (Trust, Government) - Tailwind `#1e3a8a` (blue-900).
*   **Secondary:** `Slate Gray` (Borders, Text) - Tailwind `#475569` (slate-600).
*   **Success (Pass):** `Emerald Green` - Tailwind `#10b981`.
*   **Warning (Flagged):** `Amber` - Tailwind `#f59e0b`.
*   **Danger (Fail/Missing):** `Crimson Red` - Tailwind `#e11d48`.
*   **Background:** Off-white/Light gray - Tailwind `#f8fafc` (slate-50).

## Typography
*   **Primary Font:** `Inter` (Standard, highly legible for data dashboards).
*   **Monospace Font:** `Fira Code` or `JetBrains Mono` (For displaying raw JSON or specific tender clause codes).
*   **Heading Structure:** Bold, concise headers. Normal weight for table data.
